# Personal website prototype for Marios Koulakis

This is a simple static website intended for GitHub Pages.

## Structure

- `index.html` – site content
- `styles.css` – styling
- `script.js` – tab navigation based on URL hash
- `assets/profile.jpg` – temporary profile image

## How to publish with GitHub Pages

### Simplest route

1. Create a repository named `yourusername.github.io`.
2. Upload the files from this folder to the root of that repository.
3. Commit and push.
4. GitHub Pages will serve the site automatically.

### Alternative

1. Create any repository, for example `personal-website`.
2. Upload these files.
3. In the repository settings, enable GitHub Pages and deploy from the main branch root.

## Notes for editing

- Update the text directly in `index.html`.
- Replace `assets/profile.jpg` with a higher-resolution image later.
- Add new tools, papers, or links by duplicating the existing cards.
- The navigation is tab-like and uses URL hashes such as `#research` and `#tools`.
