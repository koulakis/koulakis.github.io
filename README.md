# Marios Koulakis — personal website prototype

A simple static website for GitHub Pages.

## Structure

- `index.html` — main content
- `styles.css` — site styling
- `script.js` — small interactions for the mobile menu, active nav state, and rotating subtitle
- `assets/profile.jpg` — temporary profile image

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Push the files to the root of the `koulakis.github.io` repository and enable GitHub Pages from the `main` branch once the repository is public.
